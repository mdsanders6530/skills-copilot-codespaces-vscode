Autopilot-Onboard Runbook Flow (Visio-friendly text)

1. Start
2. Import AzIntuneAgent module
3. Authenticate
   - If Automation credential asset 'AzIntuneAgent-AppReg-Cred' exists: use Service Principal (Connect-AzAccount -ServicePrincipal + Connect-MgGraph -ClientId/Secret)
   - Else: use Managed Identity (Connect-AzIntune -ManagedIdentity -> Connect-MgGraph -Identity)
4. New-AutopilotImportFromCsv
   - Read CSV (SerialNumber, HardwareHash, AssignedUser, GroupTag)
   - Normalize hardware hash (hex -> base64 if required)
   - POST to /deviceManagement/importedWindowsAutopilotDeviceIdentities
   - Handle/Log errors per-row
5. Ensure-IntuneGroupAssignment
   - Find or create Azure AD group
   - Assign Autopilot profile to group (via deviceManagement/autopilotProfiles or deviceConfigurations)
6. Ensure-LicenseAssignment (optional)
   - Resolve subscribedSkus -> skuId map
   - For users: POST /users/{id}/assignLicense
   - For groups: enumerate members and assign per-user (or use group-based licensing if enabled)
7. Finalize
   - Output summary
   - Write job logs
   - Return status (Success/Partial/Failed)
